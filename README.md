# Firework · 我们的小蚂蚁

两个人，一只爱吃星星糖的小蚂蚁，一本慢慢写满的日记。

一个没有运行时依赖的静态宠物网页，适合 GitHub Pages。喂糖、摸摸、休息、写下日常；两位照顾者当天都参与，即点亮一次共同小火花。累计陪伴不会因中断而清零。

## 记忆

- 记忆保存在当前浏览器的 `localStorage`，刷新后保留。
- 不会自动跨设备同步，也不会把日记上传到 GitHub。
- 设置中可以修改宠物和两位照顾者的名字，并导出、导入 JSON 备份。导入按记忆 ID 合并。
- 不会因为新增互动而自动删除旧纸条；最多保存 10000 条互动，接近浏览器容量时会提示导出备份。
- 清除浏览器数据或切换域名会影响本地记忆。迁移前请导出备份。
- 目前的回应来自预设文案和已保存的纸条，尚未接入或训练语言模型。

## 开发

Node.js 20+，无需安装依赖。

```sh
npm run dev
npm test
npm run build
```

预览地址 `http://127.0.0.1:4173`。发布文件在 `dist/`。

## GitHub Pages

在仓库 Settings → Pages 选择 GitHub Actions。推送 `main` 后，工作流会测试、打包并发布。

所有资源采用相对路径，支持 `/Firework/` 项目路径。网页只包含客户端代码，不需要 API 密钥。

## 后续模型

可以先训练一个小型字符 GRU 或 Transformer，再把推理接到当前回应接口。10–100 MB 是权重文件大小，而非运行内存；CPU 推理与训练速度取决于模型结构、上下文长度和硬件。当前页面无需模型下载。
